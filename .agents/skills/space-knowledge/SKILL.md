# Space Knowledge

Support accurate, delightful astronomy content for Toma’s Space Ship's young players.

## Workflow

1. Read the relevant source material in this skill's `references/` folder before drafting. The folder can contain Markdown notes, source excerpts, citations, or other project-approved knowledge files.
2. Check names, classifications, and existing game coverage in `src/data/bodies.json` and current content examples in `src/data/learning-content.json` and `src/data/learning-content.md`.
3. Keep each card, question, or fun fact focused on one idea. Use short sentences and familiar words suitable for a five-year-old.
4. Preserve scientific accuracy. If references conflict, identify the disagreement and prefer a reliable primary source. If a detail is uncertain, say so rather than guessing.
5. Keep playful storytelling clearly separate from factual claims, and follow the content file's existing schema.

## Adding knowledge

Add project-approved source material to `references/`. Include a source title, publisher, date when relevant, and a URL or citation in each file so claims can be checked later. Keep reference notes focused; do not copy large source documents when a concise summary and citation will do.

## Output checklist

- Is the fact correct for the named object?
- Can a young child understand it when heard aloud?
- Is it brief enough for the game's interface?
- Does the wording separate fact from imagination?
- Does any changed content still match the project's data format?
